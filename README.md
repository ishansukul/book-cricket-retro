# Book Cricket Retro 🏏

Pure 90s/2000s Indian school recess nostalgia brought into a browser-native skeuomorphic arcade game.

## Features

- **Character Archetypes & Flipper Hands:**
  - **Bunty (The Last-Bench Legend):** Fast thumb riffle with ink stains, 38ms flip speed, fast stealth reflexes.
  - **Aditya (The Class Topper / Frontbencher):** Controlled fingertip glide with mechanical pencil, 65ms flip speed.
  - **Rocky (The PT Period Hero):** Heavy thumb clamp with rubber wristband, 45ms flip speed.

- **Authentic Vintage Textbooks & Notebooks:**
  - Starts strictly from a **CLOSED book cover** with realistic Indian textbook wear.
  - **NCERT Class 10 Mathematics:** Quadratic equations & trigonometry pencil margin work.
  - **Classmate 6-Subject Spiral:** Blue ruled paper with Reynolds 045 blue ink doodles.
  - **R.D. Sharma Vol. 1:** 1,180 pages of pure mathematical weight and red teacher marks.
  - **NCERT English Literature (First Flight):** Poetry scribbles and highlighter margin notes.

- **Classroom Stealth Mechanic (Teacher AI):**
  - **Writing on Board:** Safe to flip pages and score runs.
  - **Turning Around:** 1.2s warning window to slam book shut.
  - **Stare-Down:** If caught flipping while teacher is watching, immediate detention (`CAUGHT BY TEACHER!`).

- **Rules:**
  - `4` = Four (Cover Drive)
  - `6` = Six (Out of the Ground)
  - `2` = Quick Double
  - `1, 3, 5, 7` = Quick Single
  - `9` = Dot Ball
  - `0` or `8` = OUT (Clean Bowled or Caught)

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI & Animations:** Tailwind CSS, Framer Motion, Lucide Icons
- **Language:** TypeScript
